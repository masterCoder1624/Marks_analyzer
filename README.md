# Marks_analyzer
The Marks / Expense Analyzer is a beginner-friendly Python console project built to practice Array (List) Data Structure concepts.
The program allows users to input a list of numbers (such as student marks or daily expenses) and then performs various analytical operations on the data.

This project focuses on strengthening logic building and understanding how arrays work internally without relying heavily on built-in functions.

# FEATURES

1) Find Highest Value

2) Find Lowest Value

3) Calculate Average

Search for a number

Concepts Used

Array / List Traversal

Loops (for loop)

Conditional Statements (if / else)

Linear Search

Manual Min / Max Logic

Manual Average Calculation

Basic Sorting Logic

Technologies

Python 3

Console / Terminal Based Application

How It Works

User enters numbers separated by spaces.

Numbers are stored in a Python list (Array).

User selects an operation from the menu.

Program processes the data and displays the result.

#SAMPLE INPUT
Enter marks separated by space:
45 67 89 32 76

Sample Output
Highest Marks: 89
Lowest Marks: 32
Average Marks: 61.8

Learning Outcome

After completing this project, you will understand:

How arrays store and process data

How searching and sorting work internally

How to write cleaner loops and conditions

Basic problem-solving using Python
